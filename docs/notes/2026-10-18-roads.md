# Roads (2026-10-18)

Roadmap 7.2 and the roads line of 4.6. Rules checked against VCMI's pathfinder (`config/roads.json`, `lib/pathfinder/CPathfinder.cpp`).

## Scenario data

`terrain.roads` is optional and, when present, has one road code per tile, in the same order as `terrain.tiles`. Without it the map has no roads, so older scenarios load unchanged.

| Code | Road | Straight step | Diagonal step |
|---|---|---|---|
| 0 | none | | |
| 1 | dirt | 75 | 106 |
| 2 | gravel | 65 | 91 |
| 3 | cobblestone | 50 | 70 |

- The table is Heroes content (`game/heroes/road-types.js`, passed in as `content.roadTypes`). `engine/map.js` answers `getRoadType(tile)` from it.
- Roads are a separate layer, as in Heroes 3, so the terrain under a road still counts: stepping off a road costs the terrain of the tile the hero leaves.

Road data isn't validated on load: an unknown code reads as no road. `game/heroes/demo-scenario.test.js` checks the real scenario's roads.

## Behaviour

- A step uses the road only when both the tile the hero leaves and the one it enters have a road. It then costs the road on the tile it leaves, whatever the terrain under it. Otherwise the terrain cost applies as before.
- Diagonal road steps cost the road cost × √2, rounded down, and the diagonal exception uses the road cost.
- Points left after a step drop to 0 only when they can't pay the cheapest next step. On a road tile next to another road tile that is the road cost, so a hero with 50 points left on cobblestone keeps them.
- The route search picks the cheapest route, so it follows roads when they are cheaper.
- Roads are drawn above the terrain tiles as one continuous line, coloured by road type (`game/ui/terrain.css`): each road tile has an arm from its middle to the edge towards each road it joins, plus a round hub where the road ends or turns. A diagonal neighbour already joined through a straight one gets no arm, so corners draw no triangles.
- As in Heroes 3, the rollover bar, the right-click popup and the minimap don't show roads.

## Demo scenario

A road runs from the hero's start through all four towns (dirt, cobblestone, gravel, dirt). `game/heroes/demo-scenario.test.js` checks that every town is on the road network.
